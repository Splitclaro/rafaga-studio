## 2. Hallazgos

Gravedad: Crítica · Alta · Media · Baja. Estado: Corregido (con prueba) · Abierto · Bloqueado (externo).

| ID | Gravedad | Hallazgo | Evidencia | Archivo | Causa probable | Solución | Estado |
|---|---|---|---|---|---|---|---|
| F-01 | Crítica | Un vídeo largo real (>50 MB) no se puede subir. | Límite de Supabase Free: 50 MB por archivo (STATUS, «Bloqueos externos»). | Storage `originals` | Plan gratuito. | Supabase Pro (coste: requiere autorización) o subida por partes + reensamblado en el worker. | **Bloqueado** |
| F-02 | Crítica | YouTube no proporciona el archivo del vídeo ni la señal de un directo; buscar y seleccionar da identidad y metadatos, no medios. | Documentación de la API y diseño: `packages/providers/src/youtube.ts` (`nextStep`). | `packages/providers/src/youtube.ts`, `apps/web/app/app/page.tsx` | Restricción de YouTube; descargar su contenido incumple sus condiciones. | Vías legítimas implementadas: **vincular original** (archivo propio) para vídeos y **señal autorizada** (HLS) para directos; el estado y el siguiente paso se muestran según el caso (4 casos probados en navegador con API simulada). Falta una **entrada del codificador (RTMP) hacia Ráfaga**: el worker en GitHub Actions no puede recibir conexiones entrantes; hace falta un servidor de ingesta (p. ej. MediaMTX en una VPS o un servicio de directo) con coste. | **Parcial / Bloqueado** (ingesta RTMP) |
| F-03 | Alta | Sin clave de Groq ni de YouTube Data API en el entorno: las integraciones están completas pero **no verificadas contra los servicios reales**. Las tarifas del coste están anotadas de memoria. | `gh secret list`: solo `ANTHROPIC_API_KEY`, `DEEPGRAM_API_KEY`, `SUPABASE_SECRET_KEY`. | `packages/providers/src/{groq,cost,youtube}.ts` | Las claves las crea la persona responsable. | Crear `GROQ_API_KEY` (secreto de GitHub) y `YOUTUBE_API_KEY` (variable de Vercel); verificar modelos, cuota gratuita y tarifas; ejecutar la comparación sobre el material de prueba. | **Bloqueado** |

## Pendiente / decisión del propietario
1. **Registro abierto en Supabase** (*Allow new users to sign up* activado, con confirmación de correo). Cualquiera con un correo real podría crear cuenta y encolar trabajos (coste de Modal/Groq/R2 gratuitos). Hoy hay 1 usuario. Recomendación: desactivarlo y dar de alta a quien invites. No lo cambio yo (es un ajuste de seguridad de tu cuenta).
2. `oauth_token(provider)` devuelve el token al navegador de un responsable (diseño actual). Una XSS lo robaría. Mejora: que la API lo use solo en servidor con clave de servicio (hoy la regla del proyecto prohíbe la clave de servicio en la web).
3. `scheduler_runs_read` usa `using (true)`: cualquier usuario autenticado lee métricas operativas del planificador (sin datos personales). Con un solo espacio no es explotable; restringir si hay más espacios.
4. Buckets `originals`, `proxies` y `renders` sin límite de tamaño propio (los frena el límite global de Supabase Free, 50 MB). Fijar `file_size_limit` si se sube de plan.
5. Acciones de GitHub fijadas por etiqueta (`@v4`), no por SHA.
6. Sin CSP completa de scripts (Next usa scripts en línea); solo `frame-ancestors`/`object-src`/`base-uri`. Una CSP con nonces es trabajo aparte.
7. La sincronización automática transcribe (1 unidad/min) cada canción sin letra, también en subidas múltiples: avisarlo antes de subir muchas.
8. Publicación en TikTok no verificada con una app real (ver `docs/PLAN_TIKTOK_AUTOMATION.md`).

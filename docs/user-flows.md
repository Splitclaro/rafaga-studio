# Flujos de usuario (v1)

**F1 · Primer clip.** Entrar → Inicio → pegar enlace propio o subir MP4 → (opcional) «Di qué buscar» y estilo → Obtener clips → Procesamiento → Resultados. Pasos hasta ver resultados: 3 acciones.

**F2 · Revisar y comparar.** Resultados → marcar dos clips → Comparar → abrir el mejor en el Editor.

**F3 · Editar y exportar.** Editor → ajustar subtítulos/encuadre → Exportar → Exportados → descargar MP4 validado (o .zip en lote).

**F4 · YouTube propio.** Conexiones → Conectar YouTube → consentimiento de Google (lo acepta el usuario) → elegir uno de mis vídeos → el sistema pide el archivo original o lo subes.

**F5 · Publicar (manual).** Publicaciones → Preparar publicación → título/hashtags → fecha → Añadir al calendario → exportar y subir a mano. Ráfaga guarda estado y fecha.

**F6 · Lyric Studio.** Lyric → subir audio → letra → alineación → elegir estilo → generar versiones → Exportados.

Casos límite que deben tener pantalla: sin créditos, vídeo demasiado largo, formato no admitido, proceso fallido con reintento desde la fase, enlace de YouTube no descargable, conexión caducada.
